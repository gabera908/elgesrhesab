# 🌉 نظام الحسابات — الجسر المصري للإعلام والتنمية

نظام محاسبة مؤسسي متكامل بالقيد المزدوج، يعمل على Docker، بواجهة عربية (RTL) وتصميم أنيق مستوحى من هوية Claude.

## ✨ المميزات

- **شجرة الحسابات** الهرمية (المستوى 1→4) مع أكواد تلقائية
- **القيود اليومية** مع سير مراجعة (مسودة→مراجعة→ترحيل→عكس) والتحقق اللحظي
- **الشركاء** (عملاء/موردون/جهات مانحة) ببيانات ضريبية مصرية
- **السنوات والفترات المالية** مع إقفال يمنع الترحيل في الماضي
- **المرفقات** على القيود (PDF/صور/Excel حتى 10MB)
- **ميزان المراجعة** (افتتاحي + حركة + ختامي) مع اختبار التوازن
- **ميزان مراكز التكلفة** لمتابعة المشاريع والممولين
- **كشف حساب الشريك** بالرصيد الجاري
- **الأستاذ العام** بالرصيد الجاري
- **الميزانية العمومية** وقائمة الدخل والتدفقات النقدية
- **مقارنة الدخل** بالفترة السابقة مع نسب التغير
- **التصدير** Excel منسّق + CSV لكل التقارير
- **مراكز التكلفة** لتخصيص المصروفات
- **مصادقة آمنة**: Argon2id + JWT + 2FA + RBAC
- **نسخ احتياطي مشفَّر** (AES-256) واستعادة آمنة
- **تصميم RTL** متجاوب وعملي

## 🚀 التشغيل السريع

```bash
# 1. الإقلاع (يبني الحاويات ويزرع البيانات الأولية)
bash scripts/start.sh

# 2. أو يدوياً
cp .env.example .env
docker compose up -d
docker compose exec backend python -m app.seed
```

النظام متاح على: **http://localhost**

## 🔐 الأمان

- HTTPS/TLS 1.3 + HSTS
- كلمات المرور بـ Argon2id
- JWT قصير العمر + Refresh مدوَّر
- المصادقة الثنائية (TOTP)
- RBAC: مدير / محاسب / مراجع / مشاهد
- حماية من CSRF و XSS و SQL Injection
- Rate limiting على المسارات الحساسة
- سجل تدقيق غير قابل للحذف
- النسخ الاحتياطية مشفَّرة AES-256
